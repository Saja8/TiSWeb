# TiS 2027 Website

Static website for the 8th International Conference on Tethers in Space
(TiS 2027), held jointly with ISTS 2027 in Toyama, Japan.

## Development

Compile the TiS-specific stylesheet after editing `assets/scss/tis2027.scss`:

```sh
npm run sass
```
